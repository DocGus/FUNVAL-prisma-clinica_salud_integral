# INFORME DE VALIDACIÓN FUNCIONAL
## Proyecto: Clínica Salud Integral — FUNVAL

**Tipo de documento:** Plan de comprobación y acta preliminar de validación  
**Proyecto:** FUNVAL - Prisma Clínica Salud Integral  
**Entorno de validación:** PostgreSQL local — base de datos de pruebas  
**Fecha de elaboración:** 12 de noviembre de 2026  
**Estado general:** Pendiente de ejecución de pruebas funcionales

---

# 1. Objetivo

El presente documento establece las comprobaciones necesarias para verificar que el proyecto Clínica Salud Integral cumple con los requisitos funcionales, técnicos y de seguridad definidos durante el ejercicio de programación de FUNVAL.

La validación tiene como finalidad comprobar el comportamiento real de la API, su comunicación con PostgreSQL, la correcta aplicación de las reglas de negocio, el control de acceso por roles y la generación de los reportes solicitados.

La revisión contempla tanto los requisitos obligatorios como las funcionalidades adicionales implementadas por el equipo.

# 2. Alcance de la validación

La auditoría se divide en cinco módulos:

1. Configuración, persistencia y datos iniciales.
2. Recepción: pacientes y directorio médico.
3. Expedientes y autenticación.
4. Consultorio: programación, consulta y actualización de citas.
5. Gerencia: reportes y comprobaciones técnicas de entrega.

Se contemplan **32 comprobaciones de aceptación obligatorias** y **4 comprobaciones adicionales** correspondientes al desafío de seguridad de propiedad de recursos.

Total: **36 comprobaciones previstas**.

# 3. Criterios de evaluación

Cada comprobación tendrá uno de los siguientes resultados:

- **APROBADA:** el comportamiento observado coincide con el resultado esperado.
- **FALLIDA:** el comportamiento observado no cumple el requisito.
- **PENDIENTE:** la comprobación todavía no se ha ejecutado o no existe evidencia suficiente.

Los resultados descritos en este documento representan los criterios positivos que se espera confirmar durante la ejecución. No constituyen evidencia de pruebas ya realizadas.
